Local changes to the vendored check scripts (all to be upstreamed):

* absolute imports (`from _report import`) rewritten to package-relative
  (`from ._report import`); `run_checks.py` (the multi-module publisher)
  dropped in favour of `fprime_auto_checklist.runner`;
* `check_fpp_generate.py`: only `.fpp` files (not `.fppi`) are passed to
  `fpp-check` as top-level inputs;
* `check_sdd_port_table.py`: `Svc::Sched` in the SDD matches `Svc.Sched` in FPP;
* `check_hardware_run.py`: inside a git checkout an unknown recorded commit
  fails the check (previously exit 128 was treated as "not a repo");
* `check_ci_status.py`: `--repo`/`--sha` are validated before building the API URL.

The CodeQL queries are unmodified; `codeql-pack.lock.yml` is generated by
`codeql pack install` and committed to pin the pack's dependencies.

Refresh with `tools/vendor.sh <fprime-checkout> <fprime-actions-checkout>`.
